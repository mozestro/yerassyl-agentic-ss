# Справочники проекта

Здесь лежат справочники по областям проекта: по одному файлу на сервис, подсистему или сквозной паттерн.
Каждый файл — строка в таблице `CLAUDE.md`.

Порядок появления обычно такой:
1. `ARCHITECTURE.md` — общая карта: модули, связи, команды сборки и тестов, стенды.
2. По справочнику на каждую область, где была вторая задача.
3. Сквозные: обработка ошибок, конфиги, CI-грабли, тестовые паттерны.

Правила — `docs/REFERENCE_GUIDE.md`, шаблон — `docs/templates/AREA.md`.
