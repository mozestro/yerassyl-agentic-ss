# Личное

Необязательная папка для заметок о себе, которые помогают агенту давать уместные советы: опыт, цели,
план развития, самооценка, материалы для резюме.

Держать только в приватном репозитории или в памяти агента. В общие справочники не переносить.

Примеры файлов:
- `GOALS.md` — цели на год и квартал, куда хочется расти.
- `SKILL_GAPS.md` — чего не хватает до следующего уровня, план закрытия.
- `CV_MATERIAL.md` — сделанное с цифрами, для резюме и ревью.
