# Архив

Журналы и разборы «почему так было»: старые разделы `HANDOFF.md`, длинные расследования, хронология решений.

Справочники описывают текущее состояние; сюда переносится история, когда она мешает читать справочник,
но может понадобиться для ответа на «почему». Опираться на архив без сверки с кодом нельзя.

Именование: `<ОБЛАСТЬ>_JOURNAL.md`, `HANDOFF_JOURNAL.md`.
