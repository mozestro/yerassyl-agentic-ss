# Скиллы

Скилл — повторяемая процедура в `.claude/skills/<имя>/SKILL.md`. Агент загружает его, когда задача совпадает
с описанием, или по команде `/<имя>`.

## Когда заводить

- Одно и то же сделано второй раз (перевод задач в QA, актуализация ветки, печатная форма).
- Процедура с неочевидным порядком или граблями, которые легко забыть.
- Не заводить ради одной задачи и ради того, что агент и так делает правильно.

## Формат

```markdown
---
name: имя-через-дефис
description: Что делает и когда использовать — одной-двумя фразами. По этому тексту агент решает, загружать ли скилл.
argument-hint: <что передать>
---

# Заголовок

Откуда взять контекст (какой справочник прочитать первым).

## Порядок
1. Шаги с командами и критериями «готово».

## Грабли
- Что уже ломалось и как этого избежать.
```

## Правила

- Описание — про **когда**, а не только **что**: «Использовать при „покрытие не проходит“».
- Скилл ссылается на справочник, а не копирует его. Факты — в справочнике, порядок — в скилле.
- Каждое «уже ломалось» — с датой или примером, чтобы не выглядело перестраховкой.
- Стоп-правила (`git` не трогать и т. п.) повторять в конце скилла: он может выполняться без чтения `CLAUDE.md`.
- Новая грабля во время работы по скиллу — сразу в скилл.

## Набор в этом шаблоне

| Скилл | Для чего |
|---|---|
| `bootstrap` | Применить структуру к новому проекту |
| `handoff` | Завершить сессию: всё нужное — на диск |
| `update-refs` | Актуализировать справочники после изменений |
| `doc-audit` | Сверить сервис с документацией |
| `flow-trace` | Трасса запроса через все слои |
| `error-trace` | Где теряется или подменяется код ошибки |
| `lib-dig` | Ответ о библиотеке по её исходникам |
| `gen-tests` | Минимальный набор тестов |
| `coverage-gap` | Докрыть новый код до порога CI |
| `pre-push` | Проверка репозиториев перед пушем |
| `refresh-branch` | Подтянуть ветку с незакоммиченными правками на свежий main |
| `qa-handoff` | Тест-кейсы с командами и перевод задач в QA |
| `analyst-msg` | Сообщение аналитику по расхождениям документов |
