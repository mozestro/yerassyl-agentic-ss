# Правила поведения агента

Каждое правило появилось после конкретной ошибки. «Почему» записано, чтобы правило не казалось
произвольным и его не «оптимизировали» обратно.

## Проверка и честность

**Не утверждать без проверки.** Вывод по одной функции оказался неверным: потребитель читал данные из
другого места, а ложное требование уже попало в план выката и в справочники. Правило: дочитать цепочку
до конечного потребителя; непроверенное называть непроверенным; если человек говорит «на практике работало» —
искать ошибку у себя.

**Отчёт как есть.** Тесты упали — показать вывод. Шаг пропущен — так и сказать. Сделано и проверено —
сказать прямо, без оговорок.

**Своя ошибка — своя.** Если упал скрипт агента, а не сервис, это говорится первым, до перезапуска.

## Границы

**Git — только человек.** Агент не коммитит и не трогает индекс: человек должен видеть каждый коммит, а
индекс в многорепозиторном воркспейсе легко испортить чужими staged-файлами.

**Инфраструктура только на чтение и по разрешению.** Агент, сам полезший в общие кэш, логи и деплой-конфиги,
подрывает доверие и рискует чужими данными.

**Внешние документы — только по просьбе.** Вики и спецификации читают аналитики и фронтенд; лишние правки им
мешают. Публикация через API может сломать вёрстку документа (таблицы с вложениями не переживают пересохранение).

**Не плодить копии репозиториев и worktree.** Нужна правка в другой ветке, а в текущей незакоммиченное —
сказать человеку, а не создавать копию.

## Изменения

**Хирургически.** Большой дифф не читается на ревью: правка по делу тонет в переформатировании.

**Тестов минимум.** Один на новое поведение плюс нужное для порога покрытия. Тест на проброс одного поля
через DTO — шум.

**Данные отдельно от логики.** Клиент на 480 строк, из которых 70% — data-классы, перестаёт быть клиентом и
не исключается из замера покрытия.

**Общее — в общий слой.** Логика без правил конкретного модуля (например, поиск платежа, нужный трём сервисам)
живёт в шлюзе или общей библиотеке, а не копируется в каждый сервис.

**Ветки.** Пока по задаче есть открытая ветка — правки в неё. Новая — только от свежего `origin/main` и без
upstream на `main` (`--no-track`), иначе пуш из IDE уходит в защищённую ветку.

## Знание

**Факт в одном месте.** Во втором — максимум ссылка. Дублирование гарантирует, что одна копия устареет.

**Справочник — текущее состояние.** Справочник, который вели как дневник, дорос до 4500 строк с
противоречиями; передаточный файл — до 2600. Правило: найти место факта и переписать его.

**Дорогое знание — на диск сразу.** Раскопка библиотеки, найденная грабля, ID в внешней системе — в справочник
в той же сессии, иначе через неделю копать заново.

**Инструменты не во временной папке.** Генератор шаблонов, жившего только во временной папке, пришлось
восстанавливать из истории сессии.
