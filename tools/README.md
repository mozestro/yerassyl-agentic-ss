# Локальная библиотека инструментов

Скрипты, генераторы, проверялки и примеры данных, которые агент и человек используют повторно.

## Правила

- Скрипт, понадобившийся второй раз, переезжает сюда из временной папки агента. Временную папку чистят.
- Без секретов: токены и пароли читаются из окружения или локального конфига во время запуска и не выводятся.
- Пути передаются аргументами, а не зашиваются.
- Каждый инструмент — строка в таблице ниже и упоминание в справочнике области, где он нужен.

## Типичный набор

| Инструмент | Для чего |
|---|---|
| `new_code_coverage.*` | Покрытие нового кода по диффу с базой — так же, как считает CI (Sonar и т. п.) |
| `apply_texts.*` | Залить ключи локализации или конфигурации по JSON (upsert, `--force` для перезаписи) |
| `sync_docs.*` | Сверить локальные выгрузки требований с оригиналом и обновить |
| `<area>_smoke.*` | Прогон сценария на стенде по шагам с выводом статуса на каждом |
| `gen_<template>.*` | Генератор шаблонов (печатные формы, конфиги), чтобы не править руками |
