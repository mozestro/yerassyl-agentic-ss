# Докрытие до порога

1. **Замер как в CI**: тесты + отчёт покрытия → скрипт покрытия по диффу с базой (`tools/new_code_coverage.*`):
   непокрытые строки и ветки нового кода. Базу брать ту же, что у CI.
2. **Сначала исключения**: инфраструктура без логики (сгенерированный код, точка входа, чистые data-классы)
   должна быть исключена из замера — в обоих местах, где это настраивается. Логику не исключать.
3. **Докрывать минимумом**: один тест, проходящий несколько веток. Недостижимая ветка — мёртвый код, доложить.
4. Повторять до порога. Остаток из старого кода, задетого форматированием, — назвать человеку конкретно.
