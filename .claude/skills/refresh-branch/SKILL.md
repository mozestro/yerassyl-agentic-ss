# Актуализация ветки с незакоммиченными правками

1. `git fetch origin`; `git rev-list --left-right --count origin/main...HEAD` — у ветки не должно быть своих
   коммитов. Есть — стоп, сказать человеку.
2. Сохранить всё во временную папку: `git diff > unstaged.patch`, `git diff --cached > staged.patch`.
3. Откатить в рабочем дереве только изменённые отслеживаемые файлы: `git checkout -- <файлы>`. Новые файлы в
   индексе не трогать — в `main` их нет, они переедут сами.
4. `git merge --ff-only origin/main`. Отказ — стоп, доложить.
5. Вернуть правки: `git apply --exclude=<файл версии> <patch>`; версию поднять от `main`. Временные версии
   зависимостей сверить с `main` (часто там уже есть нужная).
6. Форматирование, сборка, тесты. Доложить: на каком коммите `main`, что в индексе, что вне его, пути патчей,
   предлагаемое сообщение коммита.

Новая ветка под другую задачу при грязном дереве: старые правки закоммичены — `git switch -c <ветка> --no-track
origin/main`; не закоммичены — сначала попросить закоммитить, задачи не смешивать.
