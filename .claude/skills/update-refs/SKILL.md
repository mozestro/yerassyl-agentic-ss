# Актуализация справочников

Правила письма — `docs/REFERENCE_GUIDE.md`.

1. **Затронутые справочники** — по диффу сессии и таблице в `CLAUDE.md`.
2. **Переписать факт на месте**, а не дописать в хвост. Старое неверное удалить; история — одна строка в
   «Не переделывать», длинный разбор — в `docs/archive/`.
3. **Точечно**: статусы, версии, контрольные числа, новые грабли. Не раздувать.
4. **Разделение**: постоянное — справочник, временное — `HANDOFF.md`, «почему» — «Не переделывать».
5. **Индекс**: новый файл — строка в `CLAUDE.md`.
6. **Память**: дубль содержимого справочника — ужать до указателя.
7. **Самопроверка**: продолжит ли следующая сессия по одним справочникам?
