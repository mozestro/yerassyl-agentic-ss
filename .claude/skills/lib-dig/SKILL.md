# Раскопки исходников библиотеки

1. **Найти исходники** нужной версии (из файла сборки потребителя): кэш менеджера зависимостей
   (Gradle/Maven `*-sources.jar`, `node_modules`, `site-packages`, `~/go/pkg/mod`). Нет исходников —
   `javap -p -c` / декомпилятор по бинарю.
2. **Распаковать во временную папку**, не в проект. Искать по вопросу, читать конкретный файл.
3. **Отвечать цитатой** с путём внутри архива, а не пересказом.
4. **Записать находку** в справочник (таблица «библиотека → класс → факт»), чтобы не копать второй раз.
