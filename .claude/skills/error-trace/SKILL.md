# Трассировка ошибки

1. **Эталон**: записать, как ошибка должна идти — где создаётся (код/enum), где локализуется, какой
   HTTP-статус на каждом слое, в каком формате приходит клиенту.
2. **Воспроизвести** реальным вызовом каждого слоя снизу вверх и сравнить ответ с эталоном.
3. **Частые места потери:**
   - текст ищется по ключу, которого нет в хранилище локализации → пустые строки или ключ вместо текста;
   - нижний слой бросил не то исключение, обработчик его не узнал → общий «внутренняя ошибка»;
   - обёртка вида `runCatching { … }.getOrElse { throw Свой_Код }` затирает исходный код;
   - маппер «всё неизвестное → ERROR» схлопывает бизнес-коды;
   - параллельные вызовы: упавшая задача отменяет соседние и выбрасывает исходное исключение мимо маппинга.
4. **Выход**: таблица «слой → что происходит с кодом → файл:строка», точка потери, фикс.
   Новый способ потерять ошибку — добавить в этот список.
