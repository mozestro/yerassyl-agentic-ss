# Завершение сессии

Контекст сессии умрёт, файлы останутся. Всё дорогое, что есть только в контексте, — на диск. У каждого факта
одно место.

## Куда что

| Тип факта | Место |
|---|---|
| Незакрытые нити, ветки, порядок действий при разблокировке | `HANDOFF.md` — перезаписать «Состояние» |
| Почему решили так («не переделывать») | таблица в справочнике области |
| Как устроено, команды, грабли | справочник области (`docs/reference/`) |
| Новая область без справочника | новый файл + строка в индекс `CLAUDE.md` |
| Предпочтения, договорённости, ожидания с датами | память агента, указателями на файлы |
| Скрипт, нужный повторно | `tools/` + строка в `tools/README.md` |
| Устаревшее | удалить; нужен след — `docs/archive/` |

## Порядок

1. Пройти сессию: что узнали нового, что решили и почему, что не закрыто, что изменилось в репозиториях.
2. Сверить состояние реальным `git status`/`log` по затронутым репозиториям, а не по памяти.
3. Обновить файлы по таблице. Контрольные числа (тесты, покрытие) — в `HANDOFF.md`.
4. Сводка человеку: сделано / заблокировано чем и с какой даты / следующие шаги / что от него нужно.

git add/commit не выполнять.
