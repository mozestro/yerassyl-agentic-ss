# Проверка перед пушем

Обходить репозитории с изменениями и ветки из `HANDOFF.md`.

1. **Временные версии**: локальные снапшоты зависимостей, временные репозитории пакетов, `TODO перед пушем` —
   блокер.
2. **Индекс (только чтение)**: файлы, staged и удалённые из рабочего дерева; чужие файлы в индексе;
   системный мусор (`.DS_Store`). Доложить, самому не трогать.
3. **Подозрительные локальные правки**: обёртки сборки, конфиги среды — спросить, коммитить ли.
4. **Качество**: форматирование, тесты, покрытие нового кода по порогу CI.
5. **Ветка и версия**: имя ветки под правила CI; версия поднята и не занята параллельной веткой.
6. **Порядок пуша**, если репозитории зависят друг от друга (контракты → CI → потребители).

Выход: `| Репозиторий | Статус | Блокеры | Что сделать человеку |`. git add/commit не выполнять.
